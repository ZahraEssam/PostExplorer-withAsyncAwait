# Post Explorer — Async/Await Version

A modern and cleaner web app to explore posts and their comments using **JSON Placeholder API**.  

**Features:**
- Fetches posts from JSON Placeholder
- For each post, fetches its comments
- DOM Manipulation to display posts & comments
- Uses `async/await` for cleaner and readable async code
- Handles errors with try/catch

**Tech Used:**
- JavaScript (ES6+)
- Fetch API
- Async/Await
- DOM Manipulation
